# Реклама в настройках AstroPhoto — 09.11.2026

Главная открывается без окна «Реклама и данные». Пользователь открывает его в «Настройки → Конфиденциальность → Реклама и данные». После чтения политики кнопка «Назад» возвращает к выбору в настройках.

Реклама включается после явного выбора «Разрешить». Сохранённые согласия и отказы читаются как раньше. Яндекс документирует ограничения `setUserConsent` для GDPR-региона. Подтверждения режима показа без обработки рекламных данных до согласия для текущей интеграции нет. [Документация SDK](https://ads.yandex.com/helpcenter/ru/dev/android/gdpr) · [Правила RuStore, раздел 9.8](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps).
