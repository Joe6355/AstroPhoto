## Реклама с первого запуска

Владелец хочет включить рекламу с первого запуска и убрать окно с главной. По предыдущему запросу управление показом остаётся в настройках.

В кабинете РСЯ у AstroPhoto **«Тестовый режим»**, в списке указан Google Play, ссылка на магазин отсутствует. Оба блока, нативный и App Open, активны на уровне блоков. Для коммерческих показов нужна публичная ссылка RuStore и успешная модерация приложения в РСЯ. [Карточка в РСЯ](https://partner.yandex.ru/v2/inapp/app/20351551/) · [Статусы РСЯ](https://ads.yandex.com/helpcenter/ru/monetization/app/status).

В просмотренных общих настройках AstroPhoto и основных настройках обоих блоков не найден режим ограничения обработки рекламных данных до согласия. Проверка публичных методов используемого SDK 8.6.0 подтвердила `setUserConsent`, `setLocationTracking`, `setAgeRestricted` и `setAppAdAnalyticsReporting`. Документация описывает действие согласия для GDPR-региона, а ограничение по возрасту для детской аудитории. Для передачи персональных данных соглашение РСЯ требует законного основания. До подтверждения режима для России действует существующий выбор пользователя. [GDPR](https://ads.yandex.com/helpcenter/ru/dev/android/gdpr) · [Инициализация SDK](https://ads.yandex.com/helpcenter/ru/dev/android/quick-start) · [Соглашение РСЯ](https://yandex.ru/legal/yan_dpa_ch_ru/ru).
