# Пункт 3 — одиночная съёмка JPEG (22.09.2026)

По решению владельца приложения RAW/DNG исключён из релизной проверки и удалён из активных сценариев приложения. Ранее созданные файлы пользователя не удалялись.

Статус: закрыт по решению владельца 24.09.2026 без полной проверки. Сохранение JPEG, применение ISO и выдержки подтверждены; фокус и качество на освещённой сцене не проверены.

## Проверено на Redmi 23021RAA2Y, Android 13

- Два JPEG до удаления RAW сохранились в тестовой сессии `Session_20260922_124224`.
- Camera2 сообщил для первого кадра фактические 1/30 сек и ISO 400, для второго — 1/30 сек и ISO 800; оба значения совпали с запросом.
- После установки release APK без RAW третий JPEG `AstroPhoto_20260922_190232.jpg` сохранился в `Lights/JPEG` (53 724 байта). Экран показал имя файла.
- На экране камеры доступны «Один кадр» и «Серия»; одиночная кнопка подписана «Снять JPEG». Опции RAW нет.
- `testDebugUnitTest`, `lintRelease` и `assembleRelease` завершились успешно после удаления RAW. Финальный APK установлен через `adb install -r` и запускается; три тестовых JPEG остались на месте.
- После финальной установки экран камеры показывает режимы «Один кадр» и «Серия», формат `JPEG` и кнопку «Снять JPEG». Строк RAW/DNG в иерархии экрана нет.

Проверка фактического положения фокуса и качества изображения в освещённой сцене ещё не завершена. На скриншотах этой проверки preview чёрный; сохранённый тестовый JPEG тоже почти чёрный. При неизменном положении телефона preview штатной камеры также чёрный. Повторная проверка 24.09.2026 дала тот же результат в обоих приложениях. Это не позволяет определить качество изображения AstroPhoto; нужна съёмка освещённой сцены с видимыми деталями.
