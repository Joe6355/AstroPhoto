## Выполненные проверки

1. До установки сохранены SHA-256 файлов `Pictures/AstroPhoto`, внутренних данных прежнего приложения и его APK.
2. Release установлен через `adb install` рядом с `com.example.astrophoto`. Прежнее приложение не удалялось и не обновлялось.
3. Первый запуск через `am start -W`: `Status: ok`, `LaunchState: COLD`, `TotalTime: 2659` мс. Это измерение Android Activity Manager, не отдельный замер полной готовности интерфейса.
4. В системном диалоге предоставлен доступ к камере при использовании; вводная подсказка закрыта кнопкой «Пропустить». Главный экран проверен по UI-дереву и скриншоту.
5. Повторное открытие работающей Activity успешно. Затем выполнен `force-stop` только нового release-пакета и холодный запуск: `Status: ok`, `TotalTime: 614` мс. Главный экран восстановился, вводная подсказка повторно не показалась.
6. В crash-буфере обоих процессов записей нет. В `exit-info` зарегистрирована только запланированная остановка `USER REQUESTED / FORCE STOP`; падений и ANR в проверенном запуске не обнаружено.
7. После проверки повторно вычислены SHA-256: все 1349 файлов в `Pictures/AstroPhoto`, 222 внутренних файла прежней версии (`files`, `shared_prefs`, `databases`, `no_backup`) и прежний APK совпали с исходными. Кэши в проверку внутренних данных не включались.

Код приложения не изменялся, исправления для пункта 1 не потребовались. Использован ранее собранный подписанный APK; сборка и unit-тесты в этом пункте повторно не запускались.
