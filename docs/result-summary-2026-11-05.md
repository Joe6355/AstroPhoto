# Итог обработки и сравнение с опорным кадром — 05.11.2026

Блок начат04.11, завершён05.11. Владелец разрешил обе доработки: понятный итог у фотографии и автоматический выбор исходника, по которому выравнивался результат. [Метаданные проверки](result-summary-2026-11-05.json). Пиксельные алгоритмы, RAW, публикация и подпись основной версии в этот блок не входят.

## Поведение приложения

- В просмотре результата появилась кнопка «Итог:12 из30». Она открывает отдельное прокручиваемое окно: сколько кадров использовано, что сохранено, основные причины исключения остальных, сведения об Enhanced и опорном кадре.
- Числа читаются из парного отчёта выбранного файла. Например, серия1 —12/30 и опорный27; серия2 —4/10 и опорный9. Причины показываются по-русски, без внутренних английских кодов. Для исходного fallback явно написано, что сохранён только опорный кадр; он не выдаётся за результат сложения.
- Отказ Enhanced по потере/ослаблению подтверждённых звёзд объясняется отдельно. Отказ дополнительного варианта не выдаётся за потерю основного результата.
- «Сравнить с опорным кадром» выбирает точное имя исходника из отчёта среди Lights JPEG текущей сессии. При отсутствии отчёта, пропавшем или неоднозначном исходнике остаётся явно подписанное сравнение с первым кадром. Darks/Cropped вместо него не подставляются.
- Если парный отчёт недоступен, выводятся сведения о файле; число кадров и причины не придумываются. Технические сведения с именем и путём сохранены внутри этого окна.
- Ожидание вспомогательных сведений интерфейсом ограничено5с. При задержке можно открыть сведения о файле и использовать первый исходник; поздний ответ не меняет уже показанный выбор. При новом открытии файла чтение повторяется. Это ограничение ожидания UI, а не обещание прерывания любого внешнего Android-провайдера.
- При крупном системном шрифте действия «В галерее»/«Поделиться» помещаются в меню возле имени, чтобы сохранить область фотографии. При обычном шрифте прежние кнопки остаются.

## Данные и затронутый код

Использован существующий [AppSpecificProcessingReportStore](../app/src/main/java/com/joe6355/astrophoto/processing/jpeg/v2/diagnostics/AppSpecificProcessingReportStore.kt), в нём добавлен точный поиск отчёта по изображению. Чтение [ProcessedResultReportReader](../app/src/main/java/com/joe6355/astrophoto/ProcessedResultReportReader.kt) поддерживает private fallback, MediaStore и legacy-sidecar. Проверяются имя выхода, доступная идентичность сессии, версия JSON и согласованность счётчиков; размер текста ограничен2×1024×1024 символами. Оригиналы и отчёты не переписываются.

Представление и выбор исходника: [ResultProcessingSummary](../app/src/main/java/com/joe6355/astrophoto/ResultProcessingSummary.kt), [диалог](../app/src/main/java/com/joe6355/astrophoto/ResultProcessingSummaryDialog.kt), [просмотр результата](../app/src/main/java/com/joe6355/astrophoto/ProcessedResults.kt). Сначала заканчивается чтение, затем становится доступно сравнение: быстрый тап не выбирает первый кадр до определения опорного.
