# Однократное ограниченное усиление перекрывающихся точек — 19.10.2026

`ProtectedFaintStarEnhancer` последовательно читал уже изменённый пиксель из `changes`. Если ядра нескольких найденных кандидатов перекрывались, следующий кандидат усиливал предыдущий результат. Ограничение residual gain 0,62 относилось только к одному шагу, а итог зависел от порядка кандидатов.

Это подтверждено реальными неизменяемыми RGB16-буферами предыдущего прогона `035444`: между `luminance-denoised` и итоговым `protected-faint-stars` при gain 0,4 у 124 пикселей яркость выросла сильнее допустимых 1,62 с учётом двух младших разрядов округления. Максимальный множитель — 3,474. В вариантах 0,8/0,6 таких пикселей было 117/122, максимумы — 3,139/3,098. Эти множители относятся только к локальному этапу после общей тоновой кривой.

Теперь каждое предложение вычисляется из неизменённого входного RGB16. Для перекрывающегося пикселя сохраняется предложение с наибольшей линейной яркостью. Уже записанное предложение больше не служит входом следующего усиления. Пороги поддержки, достоверности, формы, локального фона и величина усиления сохранены. Изменение касается только этого этапа; регистрация и шумоподавление не менялись.
