# Android14: исправлено падение при запуске обработки

**Падение воспроизведено и исправлено.** До изменения существующий тест завершился `InvalidForegroundServiceTypeException`; после изменения тот же сценарий прошёл на том же Android14/API34. Это новый системный сценарий, а не повтор закрытых проверок Android13 или настройка алгоритмов фотографий.

## Причина и изменение

Прежний manifest объявлял для `ProcessingForegroundService` только `mediaProcessing`. На API34 двухаргументный `startForeground` использовал этот неизвестный системе тип и завершал процесс:

```text
android.app.InvalidForegroundServiceTypeException:
Starting FGS with type unknown ... targetSDK=36 has been prohibited
ProcessingForegroundService.startInForeground(ProcessingForegroundService.kt:87)
```

В коммите **`4d3bf2132f1d041545a7c98e4672a7c4f17598c6`** изменены только:

- `app/src/main/AndroidManifest.xml`: добавлено нормальное разрешение `FOREGROUND_SERVICE_DATA_SYNC`, для службы объявлены `dataSync|mediaProcessing`.
- `app/src/main/java/com/joe6355/astrophoto/ProcessingForegroundService.kt`: на API29–34 явно передаётся `DATA_SYNC`; на API35+ сохранён прежний явный `MEDIA_PROCESSING`, на API26–28 — двухаргументный вызов.

`dataSync` в данном случае относится к локальной обработке файлов, которая перечислена в [официальном описании типов Android](https://developer.android.com/develop/background-work/services/fgs/service-types). Сетевое разрешение, сервер и синхронизация пользовательских снимков не добавлялись. Пиксельные алгоритмы, checkpoints и форматы снимков не менялись.

Подготовка кода и проверка полного CI на ноутбуке завершены; единственная зависимость сокращённого плана — подписанный кандидат сПК. Остальные отложенные работы из-за этого не возобновлять.

## Границы и что не повторять

Проверены запуск/прогресс/отмена настоящей службы на API34 с синтетической задачей. Не проверялись точность ETA реального конвейера, его фотографии, физическая камера, API26/35+, системный длительный таймаут и runtime R8. ATD оптимизирован для функциональных тестов; результат не объявляется новой визуальной приёмкой интерфейса или полной шторки.

Сокращённый план владельца: **Android14 закрыт; остаётся совместимое обновление основной установки после подписи на ПК.** Дополнительная косметика, матрица ОС/устройств, стрессовые случаи и настройка прежних серий отложены. Повторять этот API34-сценарий без изменения службы/manifest или нового дефекта не нужно.

Логи, APK, снимки службы и машинные доказательства локальны: `artifacts/android14-foreground-2026-11-02/`. Переносимые [метаданные](android14-foreground-fix-2026-11-02.json) содержат результат без фотографий/ключей. Подготовка публикации не выполнялась.
