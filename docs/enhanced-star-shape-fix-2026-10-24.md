## Изменение

`EnhancedStarSignalPreserver` после доводки проверяет тот же фиксированный исходный каталог относительно опоры. Для источников, удержанных выбранной базой, но переставших проходить индивидуальные проверки в Enhanced, он пробует плавное смешивание с выбранной базой в линейном RGB16. Используются доли восстановления 0,125 / 0,25 / 0,5 / 0,75 / 1,0; сохраняется первый проходящий вариант. Из-за квантования конечного RGB8 результат проверки не обязан монотонно зависеть от доли, поэтому двоичный поиск не применяется.

Область включает полное измерительное ядро и фоновое кольцо; снаружи добавлен плавный переход шириной 3 px. Центр совпадает с целочисленным центром измерителя. Вне выбранных областей усиленное изображение сохраняется побитно. Пиксели берутся из выбранного многокадрового результата; исходная опора используется только для измерений.

После локальных изменений повторно проверяется весь каталог. Объединение источников, удержанных базой **или исходным Enhanced-кандидатом**, должно сохраниться: защита не может стереть новый полезный источник ради восстановления другого. Пересекающиеся окна дополнительно восстанавливаются из выбранной базы; оставшееся нарушение запрещает публикацию данного Enhanced (`reference_star_retention_lost_after_enhancement`). Продолжают действовать прежние проверки контраста, цветных пятен, фона и артефактов. Основной PNG сохраняется независимо от необязательного Enhanced по прежнему правилу.

`ProfileOutputStage` передаёт действительную опору в процессор Enhanced. В отчёт добавлены `referenceBaselineRetainedSourceCount`, `referenceProtectedSourceCount`, `referenceRemainingLostSourceCount`. Пороги не менялись. Checkpoint остаётся 13: интеграция и постобработка базы не менялись, Enhanced создаётся заново на этапе сохранения.
