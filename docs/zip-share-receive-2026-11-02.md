# ZIP: получение и распаковка в локальном Проводнике — 02.11.2026

**Проверка пройдена без обновления приложений.** Основная AstroPhoto экспортировала собственную тестовую сессию; штатное «Поделиться ZIP» передало архив локальному Проводнику. Полученная копия побайтно совпала с экспортом, Проводник распаковал её, все8 извлечённых файлов совпали с содержимым ZIP. Исправлений кода не потребовалось.

Это отдельный разрешённый владельцем сценарий получателя. Раньше были проверены ZIP/CRC и открытие системного выбора; фактическая передача другому приложению оставалась открытой. Старые съёмки/обработка/матрица экспорта не повторялись.

## Реальный сценарий

1. Использована только собственная сессия **MAIN_BETA4_20261030_SMOKE**, созданная при прошлой приёмке. До теста сохранены SHA-256 всех5 её файлов:4JPEG и1PNG. Пользовательские контрольные серии для записи не открывались; «Сделать активной» не нажималось.
2. Настоящая кнопка «Экспорт ZIP» создала **`AstroPhoto_MAIN_BETA4_20261030_SMOKE_20261102_153856.zip`**, **980888байт**, в `Documents/AstroPhoto/Exports/`.
3. Архив независимо прочитан: **15 записей**, все CRC корректны, имена уникальны, абсолютных/родительских путей нет. Все5 изображений совпали с исходниками; чужих изображений нет.
4. Нажата настоящая «Поделиться ZIP». В системном `android/MiuiChooserActivity` выбран локальный пункт **«Копировать в…»**, соответствующий CopyFileActivity Проводника. Сетевые получатели, контакты и отправка другим людям не выбирались.
5. Получатель сохранил файл в заранее проверенную новую пустую папку **`Documents/AstroPhoto/QA_ZipReceive_20261102T104332Z/`**. На телефон через ADB не копировался ZIP: в эту папку его записал сам Проводник после системного выбора.
6. Полученная копия имеет тот же размер и SHA-256, что экспорт: **`fbd05768bd4d3a22a143050d6f2c21fa7530a47bb81aa3a2d3c19c7e5d6c41ac`**.
7. В Проводнике открыт именно полученный ZIP, выбрано **«Извлечь в текущую папку»**. Получены8 файлов и служебные каталоги внутри собственной папки теста. SHA-256 каждого извлечённого файла совпал с данными архива; README читается как UTF-8, frame_marks.json разбирается как JSON. Содержимое извлечённой папки также открыто в UI Проводника.

Источник ZIP и полученная копия сохранены локально для проверки. В новой папке телефона оставлены полученный ZIP и8 распакованных файлов; исходный новый экспорт остался в Exports. Это **10 новых файлов в общих тестовых каталогах**, не замена старых пользовательских снимков.
