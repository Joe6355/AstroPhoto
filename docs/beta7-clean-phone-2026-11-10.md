# Чистый запуск AstroPhoto beta.7 на Xiaomi — 10.11.2026

Подписанная **0.9.0-beta.7, код 8** установлена на Redmi Note 12 `23021RAA2Y` с Android 13. Это APK из черновика RuStore, исходники `1a8210077c6b9e19541383e10cac693267ebcef2`, SHA-256 `069e5ba513f889ac592da5e6b4da4316ddd9cb14ee7ac2fae1b681c24595b665`. Сверены подпись и хеш APK на телефоне. [Кандидат и сборка](ads-default-2026-11-10.md#подписанный-apk-и-черновик-rustore) · [Успешный CI](https://github.com/Joe6355/AstroPhoto/actions/runs/42734220859).

Для запуска с нуля создан профиль **AstroPhoto Test** (user 10). До установки пакета в профиле не было. Перед первым запуском профиль ещё не был запущен, у приложения отсутствовал каталог данных CE, доступ к камере не был предоставлен. На первом экране подтверждён системный запрос камеры поверх главной без сохранённых съёмок. Телефон передан владельцу на этом экране.

Android использует общий APK в обоих профилях. Основной профиль обновился поверх beta.6 до beta.7 с прежними UID, каталогом данных, inode и состоянием разрешений камеры, фото и уведомлений. Все **1878 общих файлов AstroPhoto**, **222 доступных файла legacy** и **640 доступных файлов QA** совпали по SHA-256. Установка и версии legacy/QA совпали с входным срезом. Сверка содержимого закрытого каталога основной release ограничена Android. [Хранение данных в профилях](https://source.android.com/docs/devices/admin/multi-user-testing).

Для возврата используется переключатель пользователей Android. При первом переключении запуск профиля и подключение ADB потребовали повторной сверки. Состояние обоих профилей и успешный запуск подтверждены после неё. Локальные журналы, хеши и снимок первого экрана находятся в `artifacts/beta7-clean-phone-2026-11-10/`. Следующий этап — ручной просмотр владельцем и отдельная доработка карточки RuStore.
