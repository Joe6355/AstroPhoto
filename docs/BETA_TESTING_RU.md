# AstroPhoto 0.9.0-beta.3 — памятка для тестирования

## Установка и обновление

1. Откройте `AstroPhoto-0.9.0-beta.3.apk` на Android и разрешите установку из выбранного приложения, если система попросит.
2. При наличии совместимой прежней версии выберите **«Обновить»**. Сессии и фотографии должны остаться доступными.
3. Если Android сообщает о несовместимой подписи, сохраните текст ошибки и обратитесь к владельцу проекта. Удаление приложения ради установки может привести к потере его внутренних данных.
4. При первом запуске выдайте доступ к камере и фотографиям. На телефоне с несколькими установками проверьте, что открыта версия **0.9.0-beta.3**.

## Короткий сценарий проверки

1. Создайте отдельную сессию с понятным именем.
2. Снимите небольшую серию JPEG. Для проверки интерфейса достаточно короткой выдержки; для съёмки неба закрепите телефон и подберите параметры под условия.
3. Откройте «Кадры сессии». Пометка «Брак» исключает кадр из обработки и MP4, сохраняя сам JPEG.
4. Запустите обработку. Для технической проверки подходит «Ручная обработка» → Average → OFF; астрономическое качество этим режимом на случайной комнатной серии не оценивается.
5. Откройте результат, проверьте 1:1 и сравнение с исходником. В редакторе примените пресет и нажмите **«Сохранить копию»**.
6. Создайте ZIP и MP4. ZIP содержит исходные кадры, результаты и сведения о сессии. Через «Поделиться» выберите приложение для передачи файла.

## Где находятся результаты

- Фотографии и PNG: `Pictures/AstroPhoto`.
- Архивы: `Documents/AstroPhoto/Exports`.
- Видео: `Movies/AstroPhoto`.

Для проверки на готовых сессиях сохраняйте новые результаты отдельными файлами. Перед важной съёмкой сделайте внешнюю копию своих фотографий.

## Границы этой беты

- Основной сценарий и обновление с сохранением данных проверены на Xiaomi 23021RAA2Y с Android 13. Совместимость с другими камерами и версиями Android ещё требует проверки.
- Доступные выдержки, ISO и фокус зависят от камеры и сохранённых результатов её проверки. Для отдельных установок требуется дополнительная проверка доступного диапазона ISO.
- Автоматическое совмещение может принять только часть серии. Почти чёрная серия может завершиться объяснённым отказом из-за недостатка пригодных кадров.
- Сложный фон, градиенты и слабые детали ещё имеют ограничения качества. Бета предназначена для ограниченного тестирования.

## Что приложить к сообщению об ошибке

Укажите модель телефона, версию Android, последовательность действий, ожидаемый и фактический результат. Добавьте точный текст ошибки и имя сессии. Диагностику можно взять в приложении, если соответствующий экран доступен. Фотографии передавайте владельцу проекта отдельно и по своему желанию.
