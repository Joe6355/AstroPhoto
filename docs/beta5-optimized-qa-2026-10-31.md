## Данные и восстановление

До установки сохранены исходная QA APK, три XML настроек и полный TAR `files/shared_prefs` размером187516928 байт. Каждый из **566** файлов архива проверен по свежему манифесту SHA-256.

- Все **1785 общих** и **222 legacy-private** файла побайтно прежние; добавлений и удалений нет.
- После runtime-прохода QA имела565 файлов: исчезли три вычисляемых файла в одном каталоге регистрации, изменились два маркера Android, добавились журнал собственного запуска и пустые отметки собственной сессии ПК. Причина удаления checkpoint отдельно не установлена; совместимость прежнего debug-checkpoint с R8 этим проходом **не подтверждена**.
- Только эти три отсутствующих checkpoint-файла восстановлены из свежего проверенного TAR, каждый сверён по исходному SHA-256. Существующие пользовательские файлы из архива не перезаписывались. Итог — **568 QA-private**, отсутствующих прежних файлов нет; **564 из566** прежних файлов побайтно совпали, включая все прежние сведения, отметки и три XML настроек. Отличаются только `profileInstalled` и `profileinstaller_profileWrittenFor_lastUpdateTime.dat`.
- Два добавления: завершённый служебный журнал собственного запуска и `frame-marks/Session_20261031_182949_PC_CAMERA_SCENE_20261031.json` с пустыми `bad/favorite/autoBad`. Фото не помечались и не редактировались.
