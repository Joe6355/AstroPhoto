## Исходный срез перед обновлением

Фактическое устройство: Xiaomi **23021RAA2Y**, Android **13/API33**. До установки служба основной AstroPhoto не работала, экран был разблокирован.

- Общие корни `/sdcard/Pictures/AstroPhoto`, `/sdcard/Documents/AstroPhoto`, `/sdcard/Movies/AstroPhoto`: сохранён манифест **1877 файлов** с SHA-256. Это хеши, а не полная локальная копия всех фотографий.
- Доступные private-каталоги: legacy **222**, QA **640** файлов; их TAR-копии сверены с манифестами. Полный private non-debuggable main недоступен для сплошного хеширования.
- Видимые исходные настройки: сессия **«новая_серия_2_окно»**, **33 с / ISO50 / AF / 10 кадров / пауза0 / таймер0**, JPEG **100**, тёмная тема. Значение 100 наблюдалось уже до этой установки; причина отличия от прежних 92 здесь не выяснялась.
- Системные значения до установки: fontScale **0,81**, stay-awake **2**, user_rotation **0**, autoRotate **1**. Старые значения 03.11, включая stay-awake0 и JPEG92, не являются исходными для этого блока.

XML/PNG настроек, APK, TAR, логи и полные манифесты находятся только в игнорируемой `artifacts/pc-main-update-2026-11-05/`.
