# Сигналы после обработки — реальный UI QA

01.11.2026, Xiaomi 23021RAA2Y / Android13. Проверен следующий открытый путь после [завершения серии](series-feedback-2026-11-01.md): сигнал из успешного завершения настоящего сложения. Алгоритмы и производственный код прежние; старые астрономические серии не использовались.

## Проверка и результат

Новый opt-in `ProcessingCompletionFeedbackDeviceTest` создаёт два собственных JPEG64×64, показывает настоящий `JpegStackingBlock`, выбирает ручную обработку/OFF и дважды нажимает **«Сложить JPEG»**. Работают штатные `JpegStacker`, координатор, служба и обработчик успеха UI. Тест **не вызывает `notifyCompletionFeedback` напрямую**.

Перед каждым запуском через `CameraSettingsStore` задаются реальные настройки QA: `soundAfterProcessing` и `vibrationAfterProcessing`. Компонент читает их в обработчике успешного завершения. После теста исходные значения и байты XML восстановлены.

| Режим | Результат |
|---|---|
| Сигналы включены | Создан PNG; AudioFlinger показал поток PID/UID QA, вибратор — завершённый эффект200мс от QA |
| Сигналы выключены | Создан второй PNG; воспроизведения и нового запроса вибрации нет |
| Очистка | Собственных аудиопотоков нет после ограниченного ожидания; перед вторым запуском звук не активен |
| Результаты | Оба PNG полностью декодированы как64×64; имена различны, исходные JPEG совпали по SHA-256 |

**1 Android-тест прошёл за13,312с.** Два callback успешного завершения и два результата подтверждены. Наблюдение очистки после первого снимка состояния заняло2247мс; это метрика освобождения ресурса, а не длина слышимого сигнала. Громкость мультимедиа была **11/15** и не менялась. Активная сессия не переключалась.

Тестовый APK собран за18с после исправления ошибки компиляции в новой очистке теста: `cancel` возвращает `Unit`, поэтому вместо `join` ожидается завершение собственного состояния. Первый журнал ошибки сохранён; приложение на телефоне до успешной сборки не менялось. После успешного прогона добавлено ограничение opt-in теста Android12+ для используемого системного дампа; финальная компиляция успешна за7с. На проверенном Android13 тело теста не изменилось.

Физическое подтверждение владельца для этого нового запуска запрошено, но пока не получено. Ранее владелец подтвердил звук и вибрацию серии; это отдельный результат. Этот блок подтверждает путь **Average/OFF в QA**. Автоматический профиль, ошибка/отмена, нажатие переключателей в настройках и runtime основного оптимизированного APK здесь не проверялись. Качество звёзд на синтетических64×64 не оценивается.
