**Короткое описание**

> Ручная съёмка звёзд, серии кадров и обработка ночных фотографий.

**Полное описание**

> AstroPhoto помогает снимать ночное небо на смартфон и собирать результат из серии фотографий.
>
> - Снимайте серии JPEG с таймером и интервалом между кадрами. Настраивайте ISO, выдержку и фокус в пределах возможностей камеры телефона.
> - Храните кадры по сессиям, отмечайте неудачные снимки и добавляйте тёмные кадры для коррекции шума.
> - Складывайте кадры методами Average, Median и Sigma. Доступны выравнивание, сравнение с исходником и редактор результата.
> - Сохраняйте результат в PNG, экспортируйте сессию в ZIP или создавайте таймлапс MP4.
>
> Для съёмки и обработки регистрация не нужна. Фото хранятся на устройстве. Рекламу можно включить или отключить в настройках.

**Что нового**, если поле обязательно для первой версии

## Данные и разрешения

| Сценарий | Ответ для формы |
|---|---|
| Фото, EXIF и сессии | Чтение и сохранение локальных файлов для съёмки, обработки и экспорта. Фото и сведения о сессиях рекламному SDK не передаются. Экспорт в другое приложение выполняется по действию пользователя. Системное резервное копирование зависит от настроек Android. |
| Идентификаторы и данные рекламных запросов | При включённой рекламе Yandex Mobile Ads может обрабатывать рекламный ID, IP, сведения об устройстве, приложении и рекламных событиях для показа и учёта объявлений. Пользователь выбирает, включать ли рекламу. |
| Учётная запись | Для работы AstroPhoto учётная запись и вход не нужны. |
| Разрешения | Камера для съёмки. Доступ к изображениям для старых сессий. Уведомления, foreground-службы и вибрация для съёмки и обработки. Сеть и рекламный идентификатор для SDK. |

В черновике сохранены четыре категории: фотографии, видео, файлы и документы, ID устройства или другие идентификаторы. RuStore запросил обоснование для `CAMERA`, `POST_NOTIFICATIONS`, `READ_EXTERNAL_STORAGE`, `READ_MEDIA_IMAGES` и `WRITE_EXTERNAL_STORAGE`. Пояснение к каждому сохранено. [Декларация для beta.6](https://github.com/Joe6355/AstroPhoto/blob/34257370f9f3ede7f6c4750a89339527478903c4/docs/DATA_DISCLOSURE_RU.md) · [Форма RuStore](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/new-version-app/declare-app-permissions/how-to-declare-permissions).

RuStore автоматически отметил **Google Mobile Ads (AdMob)** и **Yandex Mobile Ads**. Обе отметки заблокированы для редактирования. Подключён Yandex Mobile Ads SDK 8.6.0. Под именами пакетов Google Ads в DEX найдены только три класса `com.google.android.gms.ads.identifier`. Объявлений компонентов AdMob в manifest APK нет. Пояснение о компоненте рекламного ID и фактическом SDK сохранено в технических сведениях. Локальная сверка `artifacts/rustore-beta6-draft-2026-11-09/apk-dex-sdk-check.txt`.

RuStore допускает для 0+ и 6+ только неперсонализированную рекламу без обработки персональных данных ребёнка. Для выбранной отметки 0+ нужно подтвердить соответствие режима SDK. Ответ на технический вопрос о показе с первого запуска не является отдельным обязательным документом RuStore. [Правила рекламы RuStore, раздел 9](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps).
