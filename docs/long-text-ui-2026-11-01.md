# Длинные названия и сообщения при 200% — 01.11.2026

Исправлены три существующих UI-компонента: длинные названия сессий и результатов видны целиком, сообщение о проблемном результате больше не сжато рядом с миниатюрой, кнопки «Открыть»/«Пресеты» переносятся целиком. На Xiaomi 23021RAA2Y / Android13 успешно проверены **пять сценариев:3+2**. Обычный заголовок остаётся компактным. Обновлена только QA; установленная основная signed beta.5 пока без этих новых UI-правок.

## Изменения

- [AstroComponents.kt](../app/src/main/java/com/joe6355/astrophoto/ui/AstroComponents.kt): при масштабе шрифта от150% общий заголовок занимает ширину под навигацией/действиями и переносится без многоточия; при обычном шрифте прежняя компактная строка.
- [SessionBrowser.kt](../app/src/main/java/com/joe6355/astrophoto/SessionBrowser.kt): имя сессии над строкой обложки/сведений, по ширине карточки, без ограничения двумя строками.
- [ProcessedResults.kt](../app/src/main/java/com/joe6355/astrophoto/ProcessedResults.kt): имя файла и тип результата над миниатюрой; ошибка/предупреждение под ней по ширине карточки. Текст заглушки ошибки оформлен как небольшая подпись. `FlowRow` переносит кнопки действий, сохраняя слова и существующие callbacks/ограничения доступа.

Алгоритмы, параметры обработки, сохранение/декодирование снимков и версия beta.5/code6 не менялись. Эталоны фотографий заморожены.
